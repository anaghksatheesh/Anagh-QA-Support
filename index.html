Issue log

Real problems from Adhyora, the college app I build and maintain. Tap one to see how I handled it.

Login lost on iPhone home-screen appiOS Safari PWA
Symptom
Users on iPhones were logged out or saw stale pages after reopening the installed app.
Cause
Safari’s back-forward cache and the history stack behaved differently from Android and desktop.
Fix
Reworked how the app restores sessions and handles page history on iOS.
Medical leave and event attendance showing wrongAttendance
Symptom
Leave and event attendance did not match what staff had entered.
Cause
A date mismatch, stale cached data and missing checks for overlapping camps.
Fix
Corrected the date handling, refreshed the cache and added overlap checks.
Push notifications going to the wrong placeNotifications
Symptom
Tapping a notification did not open the right screen.
Cause
Routing logic was split between the service worker and the client code.
Fix
Fixed the routing across both files so the tap lands on the correct page.
Data access rules reviewed and tightenedSecurity
Symptom
A security audit found gaps in login PIN checks and in what data users could read or write.
Cause
Database rules were too loose for a multi-college, multi-role app.
Fix
Rewrote the Firestore rules with college-scoped, role-based checks.
Renaming a subject broke linked recordsData consistency
Symptom
After a subject was renamed, older records still showed the old name.
Cause
The change did not carry through to everything that referred to it.
Fix
Added a rename cascade so linked records update together.

How I troubleshoot

The same five steps, whether it is a bug report from a user or a failing test.

Reproduce

Get the exact steps, device, browser and account. If I cannot make it happen, I ask until I can.

Inspect

Look at the data, the console and the network calls before guessing.

Find the cause

Separate the symptom from the reason it happens, so the same bug does not return.

Fix small

Change as little as possible, then retest the original case and the things around it.

Tell the user

Explain what was wrong and what changed in plain words, and write it down for next time.
